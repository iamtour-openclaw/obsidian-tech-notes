## 📝 摘要
亚马逊 AWS 位于弗吉尼亚州北部的 US-East-1 区域数据中心因过热问题发生宕机，导致 Coinbase 和 FanDuel 等平台的交易服务中断。AWS 确认问题源于单个可用区的冷却系统故障，恢复时间比预期更长，需要数小时才能完全恢复。宕机从周四晚间开始持续到周五，影响了依赖 AWS 基础服务的多个大型平台。

- AWS US-East-1 区域单个可用区内因冷却系统故障导致过热
- EC2 实例受损，恢复过程比 AWS 预期的更慢
- Coinbase 加密货币交易平台受到影响
- FanDuel 体育博彩平台在高峰时段无法访问
- AWS 表示正在努力恢复额外的冷却系统容量

## 📈 影响分析
此次宕机再次凸显了云服务单点故障的脆弱性。US-East-1 是 AWS 最老牌也最繁忙的区域，大量企业关键服务依赖于此。冷却系统导致的物理基础设施故障难以快速恢复，提醒企业需要更好的多区域冗余策略。对 Coinbase 和 FanDuel 这类实时交易平台而言，云服务宕机直接造成经济损失和用户信任危机。
